# 🌙 Lunora — Aesthetic Responsive Website

**Lunora** is a modern, responsive, and visually calming website inspired by the harmony of art, peace, and imagination.  
It features smooth layouts, grid-based design, and elegant typography — crafted with HTML, CSS, and JavaScript.

---

## ✨ Features

- 🎨 **Aesthetic Visuals** — A beautiful hero section with calming gradients and background art.  
- 📱 **Fully Responsive** — Works perfectly on desktop, tablet, and mobile screens.  
- 🖼️ **Grid Layout** — Cleanly organized sections for Art, Words, and Inspiration.  
- 🌗 **Minimal UI** — Simple, modern navbar with circular icon branding.  
- 🔄 **Smooth Animations** — Subtle fade and hover effects for an elegant user experience.  
- ⚡ **Lightweight** — Pure HTML, CSS, and vanilla JavaScript — no frameworks required.

---

## 🧱 Tech Stack

- **HTML5**  
- **CSS3 (Grid & Flexbox)**
- **Responsive Concepts**
- **Font Awesome Icons**
